# AI Image Generation (Epic 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Inside the design-request flow, a user generates a brand-aware design image; they can download it, save it as a brand asset, or attach it to the design request as a reference for the design team.

**Architecture:** A pluggable image config (default Bedrock Stability Stable Image Core, us-west-2) drives `generateBrandImage`, which calls Bedrock `InvokeModel` directly via `aws4fetch` SigV4 (the AI SDK's Bedrock image path only supports the legacy Amazon request shape — see spec §3 spike). Generated bytes are written to R2; three output actions reuse existing rails (download route, `brand_assets`, the design request's `referenceImageUrl`).

**Tech Stack:** Next.js App Router, Bedrock `InvokeModel` via `aws4fetch` (already in the tree), Cloudflare R2 (`src/lib/storage.ts`), Drizzle/Postgres, vitest.

## Global Constraints
- Package manager (WSL): `corepack pnpm`; never bare `pnpm`; never `npm install`.
- Default image model **`stability.stable-image-core-v1:1`**, provider `bedrock`, region **us-west-2**, ALL env-overridable: `AI_IMAGE_PROVIDER` (default `bedrock`), `AI_IMAGE_MODEL` (default the Core id), `AI_IMAGE_REGION` (default `us-west-2`). Mirror `resolveProviderConfig`'s global-default + env shape.
- Reuses existing AWS SigV4 creds (`AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`, optional `AWS_SESSION_TOKEN`).
- Every generation endpoint: auth → rate-limit → `checkBrandAccess(userId, brandId, "manage_content")` → `requireVerifiedEmail` (spends money) BEFORE the model call. Metered per image — set request-size bounds; return clean JSON errors (never throw to client).
- Save-as-asset MUST validate the R2 key is under the caller's `generated/<brandId>/` prefix (no arbitrary/cross-brand object save).
- Migrations (if any): hand-written SQL via `scripts/migrate.mjs`; drizzle/meta gitignored. (This epic likely needs none — `brand_assets` exists.)
- Only "why" comments; biome + `tsc --noEmit` clean before each commit.
- Commit trailer: `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- Generated images are DRAFTS/references — UI must not imply final brand-approved assets; state per-image cost.

```ts
import { AwsClient } from "aws4fetch";
import { resolveImageConfig } from "./image-config";

function requireEnv(name: string): string {
  const v = process.env[name];
  if (!v) throw new Error(`Missing ${name} for image generation.`);
  return v;
}

// Stability text-to-image on Bedrock: request { prompt, mode, aspect_ratio, output_format };
// response { images: [base64], seeds, finish_reasons }. (Amazon Nova/Titan use a different
// taskType schema — this adapter targets the active Stability models. See spec §3.)
export async function generateBrandImage(
  { prompt, aspectRatio = "1:1" }: { prompt: string; aspectRatio?: string },
): Promise<{ bytes: Uint8Array; contentType: string }> {
  const { model, region } = resolveImageConfig();
  const aws = new AwsClient({
    accessKeyId: requireEnv("AWS_ACCESS_KEY_ID"),
    secretAccessKey: requireEnv("AWS_SECRET_ACCESS_KEY"),
    ...(process.env.AWS_SESSION_TOKEN ? { sessionToken: process.env.AWS_SESSION_TOKEN } : {}),
  });
  const url = `https://bedrock-runtime.${region}.amazonaws.com/model/${encodeURIComponent(model)}/invoke`;
  const res = await aws.fetch(url, {
    method: "POST",
    headers: { "content-type": "application/json", accept: "application/json" },
    body: JSON.stringify({ prompt, mode: "text-to-image", aspect_ratio: aspectRatio, output_format: "png" }),
  });
  if (!res.ok) {
    const detail = await res.text().catch(() => "");
    throw new Error(`Bedrock image generation failed (${res.status}): ${detail.slice(0, 300)}`);
  }
  const json = (await res.json()) as { images?: string[] };
  const b64 = json.images?.[0];
  if (!b64) throw new Error("Bedrock returned no image.");
  return { bytes: Uint8Array.from(Buffer.from(b64, "base64")), contentType: "image/png" };
}
```
(aws4fetch derives service `bedrock` + region from the request host, so no explicit service config is needed. Verify the Stability response field name is `images` against the mock; if the live schema differs, the adapter is the single place to adjust.)
